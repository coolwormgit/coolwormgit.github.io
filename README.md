# OTT-X site

Landing page and privacy policy for OTT-X, an IPTV player for LG webOS.

Served by GitHub Pages from this branch:

- https://coolwormgit.github.io/  — landing page
- https://coolwormgit.github.io/privacy.html  — privacy policy

The privacy policy is the URL required by the Google OAuth consent screen before the app
can be published, and it describes the optional encrypted Google Drive backup.
